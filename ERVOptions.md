# ERV Options
Laying out further ductless ERV options and their set up.
* VT-501 either KCVents, Weiworld, etc.

## Breakdowns

### T-501
This unit has a remote and buttons on device so you don't have to connect it WiFi but it does also have bluetooth and WiFi control. Unfortunately, that WiFi connection is via Tuya which has some security concerns. So far the best way around this looks like [tuya_local](https://github.com/make-all/tuya-local). Important, double check the name, tuya_local is an active project and quickly integrates the VT-501 with all its settings where other repositories are less customized.

Connecting to Tuya and getting the device information can be a bit of a pain but it seems like this respository doesn't need a full Dev sign up. Will retry and confirm this in the future.
